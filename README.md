# 태양타로

[사이트 열기](https://shgudtjq-star.github.io/sunlight-tarot/)

GitHub Pages에서 바로 열리는 정적 사이트입니다. 게시 설정은 Settings → Pages → Deploy from a branch → main → /(root)입니다.

- 오늘 한 장과 세 장 리딩은 한국 날짜·주제·색으로 결정됩니다.
- 문의 링크는 index.html에 있습니다. 채팅은 https://pf.kakao.com/_zMxcsn/chat 에서 열립니다.
- 새 후기는 카카오 채팅으로 받습니다. 작성자가 공개에 동의한 후기는 reviews.json에 이름과 내용을 name, text 키로 추가해 게시할 수 있습니다.
- 대표 미리보기는 assets/share.jpg이며 방문자 리딩으로 만든 스토리는 1080×1920 PNG입니다.
