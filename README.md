# 태양타로

[사이트 열기](https://shgudtjq-star.github.io/tarot/)

GitHub Pages에서 바로 열리는 정적 사이트입니다. 게시 설정은 Settings → Pages → Deploy from a branch → main → /(root)입니다.

- 오늘 한 장과 세 장 리딩은 한국 날짜·주제·색으로 결정됩니다.
- 카카오 채널 홈과 운세7 썬라이트 프로필 링크는 index.html에 있습니다. 견적·1:1 문의는 이메일과 전화로 받습니다.
- 새 후기는 작성 후 복사하거나 이메일 앱으로 보낼 수 있습니다. 작성자가 공개에 동의한 후기는 reviews.json에 이름과 내용을 name, text 키로 추가해 게시할 수 있습니다.
- 카드 앞면에는 파멜라 콜먼 스미스의 Rider–Waite–Smith 78장 삽화를 사용합니다. 마이너 아르카나에는 완드·컵·소드·펜타클이 각 14장씩 있습니다.
- 대표 미리보기는 assets/share.jpg이며 방문자 리딩으로 만든 스토리는 1080×1920 PNG입니다.
